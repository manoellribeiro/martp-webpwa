## Status

This is a freshly scaffolded SvelteKit app (`sv create --template minimal --types ts`), intended to become a PWA. There is no application code yet beyond the default route and layout, and no PWA pieces (service worker, web manifest) have been added. Update this file as real architecture lands.

## Commands

Package manager is **pnpm** (`engine-strict=true` in `.npmrc`).

- `pnpm dev` — start the Vite dev server (`pnpm dev -- --open` to open a browser tab)
- `pnpm build` — production build
- `pnpm preview` — serve the production build locally
- `pnpm check` — run `svelte-kit sync` then `svelte-check` (the only static check; there is no linter or formatter configured)
- `pnpm check:watch` — same, in watch mode

There is no test runner configured. Add tooling with `pnpm dlx sv add <addon>` (e.g. `vitest`, `playwright`, `eslint`, `prettier`, `tailwindcss`).

## Stack and conventions that differ from older SvelteKit projects

- **SvelteKit 3 / Svelte 5 / Vite 8 / TypeScript 6.** Much online material targets older versions; prefer the current docs at svelte.dev.
- **No `svelte.config.js`.** SvelteKit options (adapter, compiler options) are passed directly to the `sveltekit()` plugin in `vite.config.ts`. Put kit config there.
- **Runes mode is forced** for all project files (not `node_modules`) via `compilerOptions.runes` in `vite.config.ts`. Use `$props()`, `$state()`, `$derived()`, `$effect()` and `{@render children()}` — not `export let`, `$:` reactive statements, or `<slot />`.
- **Library alias is `#lib`, not `$lib`.** It is defined through the `imports` field in `package.json` (`#lib` → `src/lib/index.js`, `#lib/*` → `src/lib/*`). Import as `import x from '#lib/assets/favicon.svg'`.
- `tsconfig.json` extends `$app/tsconfig` (generated by `svelte-kit sync`) with `strict: true`. If types look broken, run `pnpm check` or `pnpm prepare` to regenerate `.svelte-kit/`.
- **Adapter is `adapter-auto`.** It only supports certain hosts; swap it in `vite.config.ts` once a deploy target is chosen (a static/offline-first PWA would typically use `adapter-static`).

## Layout

- `src/routes/` — file-based routing (`+page.svelte`, `+layout.svelte`, etc.)
- `src/lib/` — shared code, imported via `#lib`
- `src/app.html` — HTML shell; `src/app.d.ts` — global `App` namespace types
- `static/` — files served as-is from the site root
